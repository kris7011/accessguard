Runners

A runner is a small program in your own environment. It claims approved scans, reads test credentials locally, scans only the targets you list in its configuration, and sends back a report without credentials or response content. AccessGuard's servers never contact your test environment.

Set up a runner

  1. Install the wheel file you received from us into a virtual environment (Python 3.11 or newer, no other dependencies): 
    python -m pip install ./accessguard-<version>-py3-none-any.whl
    The runner is not on PyPI during the beta; do not use pip install accessguard until we announce it. Installation details.
  2. Create a token below and set it: 
    export ACCESSGUARD_RUNNER_TOKEN=agr_…   # PowerShell: $env:ACCESSGUARD_RUNNER_TOKEN = "agr_…"
  3. Write runner.toml next to a credentials file (JSON, test user id → credential; keep it out of git): 
    [control_plane]
url = "{{ public_url }}"
token_env = "ACCESSGUARD_RUNNER_TOKEN"

# Only these origins can be scanned, whatever a job asks for.
[[targets]]
origin = "{% if projects %}{{ projects.0.config.target.origin|default:'https://staging.example.com' }}{% else %}https://staging.example.com{% endif %}"
zone = "public"            # loopback | private | public
credentials_file = "accessguard-credentials.json"
# max_requests = 2000      # optional local cap
  4. Start it: 
    accessguard runner --config runner.toml
