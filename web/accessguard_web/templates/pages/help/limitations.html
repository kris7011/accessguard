AccessGuard is a focused tool. Know what a passing result does not mean:

  • Only GET requests are sent: write operations (POST, PUT, PATCH, DELETE) are not tested.
  • Only the users, records, lists and endpoints you declare are tested; there is no crawling or endpoint discovery.
  • Pagination, filters and query parameters of lists are not tested.
  • Protected values are matched exactly in JSON responses; values in HTML, plain text or transformed form are not detected (such responses are inconclusive, never passed).
  • Field-level authorisation beyond the declared protected fields, side channels (timing, error messages, id enumeration) and the strength of your authentication are not tested.
  • Injection, XSS, misconfiguration and dependency vulnerabilities are out of scope.
  • Results on the synthetic demo say nothing about detection rates on real systems.
  • The AI assistant can be wrong. It never decides whether something is a violation or whether it is fixed.
