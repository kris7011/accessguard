Is it safe to point at production? AccessGuard is designed for test environments with dedicated test users. It only reads, paces its requests and stops at a budget, but testing production is your decision and responsibility.

Why a runner instead of scanning from the cloud? So that credentials and response content stay with you, and so internal staging systems can be tested without opening them to the internet.

Does the AI decide what is a vulnerability? No. A deterministic engine judges every check from the evidence. The AI only drafts configuration and explanations.

Does AccessGuard use AI to choose which checks to run first? No. We compared a local model with simple rules for ordering checks and found no reliable advantage, so scans run every check in a fixed order with a budget that covers them all.

What about GraphQL or gRPC? Not yet: the engine tests JSON over HTTP GET.

Can I export results? Yes. Every scan report can be downloaded as JSON, and the offline CLI writes JSON and HTML.
