The same engine runs offline from a scan spec, so you can scan a preview environment on every change.

  1. Download the scan spec from your project page (accessguard-spec-N.json). It contains the policy, target and limits, never credentials.
  2. In CI, write the runner configuration and the credentials file from your CI secrets, then run:
accessguard scan --spec accessguard-spec.json --config runner.toml --out reports/accessguard

Exit codes: 0 all checks passed · 1 violations · 3 incomplete or needs review · 4 configuration refused · 130 cancelled. Only a complete pass returns 0. The report is written as JSON and HTML.
