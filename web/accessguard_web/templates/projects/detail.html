About this demo

This project tests a synthetic projects API with two organisations (orbit and quasar), owners and viewers, one roadmap shared between them and owner-only billing. Its flawed version contains three access-control bugs. A platform runner scans it, exactly like your own runner will scan your API.

  1. Start the scan and watch it run.
  2. Read the findings, their evidence and the fix guidance.
  3. “Deploy” the fixed version below, then retest the findings: they are resolved only if the retest passes.
