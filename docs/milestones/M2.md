# Milestone 2: bounded adaptive agent

**Delivery status: M2 implementation with mock and contract verification.** The agent loop, its
limits and the Ollama adapter are verified with a scripted test adapter, mocked model clients
and a local fake Ollama HTTP server. **No real language model has been run**, so the real-model
part of M2 stays open. Nothing here documents the quality of an AI model or an advantage over
the baseline.

Branch: `feature/m2-adaptive-agent`, based on `ab8bdb0` (end of M1). Not pushed, not merged.
Version 0.3.0.

## Design summary

See [ADR 0007](../adr/0007-bounded-adaptive-agent.md) (agent) and
[ADR 0008](../adr/0008-selection-strategy-evaluation.md) (evaluation).

```text
            ┌──────────── ModelView (aliases, enums, ints) ────────────┐
            │                                                          ▼
CheckRunner.preflight ─► AgentLoop ──ModelRequest──► ModelClient (Ollama | scripted)
                            ▲  │                                       │
                            │  └◄── parse_action (strict contract) ◄───┘ ModelReply (untrusted)
                            │         run_check(alias) | stop | rejected
                            ▼
                  CheckRunner.execute(approved check) ──► RequestGate ──► ScopedHttpClient
                  (deterministic verdict)                 (budget, deadline, stop; also
                            │                              bounds every model call)
                            ▼
              CheckRunner.finish (retests) ─► build_report (schema 1.2, run.agent)
```

## Evaluation outcome (scripted adapter)

The scripted `follow-up` heuristic matched the deterministic baseline at every budget. It gave
no advantage. Seeded random orders found the first expected finding earlier on these fixtures,
because the flawed resources are declared late in each policy. At full budget, every strategy
found every expected finding, with 0 false positives. Details and caveats are in
[evaluation.md](../evaluation.md).

## Not done or not verified

- **Real model: not run.** Ollama is not installed on the development machine, and this
  milestone did no model installation and made no paid API calls. Still open:
  - `tests/e2e/test_real_model.py`
  - `accessguard_eval run --model ollama:<name>`
  - real-model latency, invalid-reply rate, stability at temperature 0, and context-window
    limits

  The adapter's wire format follows the official Ollama API documentation (checked
  2026-10-26) and is contract-tested against a fake server only.
- GitHub Actions has not run (nothing pushed). Python 3.11, Linux and macOS are not verified
  locally.
- The scripted adapter is a deterministic heuristic, so its evaluation results describe the
  mechanics, not AI.
- Only 4 small synthetic fixtures. Results are sensitive to declaration order and say nothing
  about real applications.
- One model call per check; the state grows linearly with the number of checks.

## Missing input for completing M2's real-model verification

An installed Ollama model, or another provider and credentials authorised by the owner. With
one available, run:

```powershell
$env:PYTHONPATH = "src;lab;evaluations"
$env:ACCESSGUARD_REAL_MODEL = "<model>"
py -3 -m unittest tests.e2e.test_real_model -v
py -3 -m accessguard_eval run --model ollama:<model> --model-timeout 120 --out reports\eval-real
```

Then record the reported digest, version, settings and results here.
